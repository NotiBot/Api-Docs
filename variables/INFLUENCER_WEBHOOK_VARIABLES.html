    avatar: boolean;

    kinds: readonly InfluencerNotificationKind[];
    name: InfluencerWebhookVariable;

Every variable the panel's webhook name / avatar take, for the editor's variable picker. Write them in braces: {memberName}.

  • kinds: the notifications that fill it. Anywhere else it comes out empty - so {streamerName} in a name that also posts X / Club posts reads blank there; offer {creatorName} beside it.
  • avatar: usable as the whole avatar field (webhookAvatarUrl: '{memberAvatar}'). The member ones need the member to still be in the server; if they left, a name variable is empty and the avatar falls back to the bot's. Any other notification placeholder also works in the name.
