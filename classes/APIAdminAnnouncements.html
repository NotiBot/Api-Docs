Class APIAdminAnnouncements

Site announcements - the developers' side. Every method is developer-only (403 otherwise) and NOT behind the siteAnnouncements flag, so announcements can be drafted before launch. Every write refreshes what the site shows.

Publishing with postToDiscord posts it to the site-updates Discord webhook ONCE (only if the server has one configured); postedToDiscordAt says when.
