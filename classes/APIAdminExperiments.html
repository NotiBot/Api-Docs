Class APIAdminExperiments

A/B experiments (promos, offers). Staff only for the admin methods (403 otherwise); every change is audit-logged. The two create...ExperimentEvent methods are for the dashboard: report what the viewer saw and did, for the arm the server gave them (a mismatched or preview arm answers { recorded: false } and is not counted).

getAdminExperimentResults

  • getAdminExperimentResults(__namedParameters): Promise<WebResponse<ExperimentResults>>

  • Results: per variant - exposures, clicks, conversions (adopt: the server turned the feature on within 7 days of first seeing it; buy: an attributed purchase within 14 days), revenue, conversion rate, lift and p-value vs control - plus likelyWinner (beats control at p < 0.05 with 200+ exposures each, or control when the promo hurts) and daily view / click / dismiss counts. Shown only: "Make winner" is still a staff click.
