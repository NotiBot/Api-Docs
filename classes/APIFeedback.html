Class APIFeedback

The feedback board - ideas and private requests, votes, follows (replaces Fider at feedback.noti.bot).

── WHO SEES WHAT ────────────────────────────────────────────────────────── Reads work logged out: pass auth ONLY when the user is logged in. With a session the server answers for that user (premium-only boards, their own hidden posts, staff view) and marks the response private, no-store; without one it answers the public view and lets it be cached. Never cache a logged-in response on the page side as if it were public.

Behind the feedback launch flag: while it is hidden for the caller every method 404s. A post the viewer may not see is 404 too, never 403 - do not show "forbidden", show "not found".

── REFUSALS ─────────────────────────────────────────────────────────────── A refused write is { status, error: { code } }, code from FeedbackErrorCode. voteRefusal / commentRefusal on a post's viewer tell you up front why the buttons are off (banned, new account, archived board, locked post), so the page can say so instead of letting the click fail.

── TEXT ─────────────────────────────────────────────────────────────────── title is plain text. body is MARKDOWN, stored raw: render it with an allowlist (no raw HTML, images only from Noti's own host, links rel="nofollow ugc noopener"). The server does not sanitise HTML for you.
