Class APIGuildMembers

Member pickers - so settings that store Discord user ids can offer a search box instead of asking owners to paste ids. Used for: users for a live role (usersForLiveRole on every creator) and a giveaway's host (hostId), and any future member field. Read only.

  • searchGuildMembers: members whose username or server nickname starts with query. A pasted id or <@id> mention returns that one member. Debounce on the page; results are cached server-side for 30s.
  • getGuildMembers: saved ids back to names and avatars, to show a stored list. Ids that left the server come back in missing - show them as "Left the server" rather than dropping them silently.

503 when the server's shard cannot be reached; 400 for an empty query or more than 100 ids.
