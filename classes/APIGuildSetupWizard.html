  • Apply step: creators and the welcome channel become the AI assistant's own cards (AssistantProposal, same checks, plan locks and permission hints - render and apply them with the assistant card component; do not report assistant outcomes for them). Every other kept feature is a link to its page with the picked channel / role. picks: need key -> the channel / role id chosen (or created) in the wizard. problems: why a card could not be made (e.g. already set up). No AI is called; works while the assistant itself is off.

createGuildSetupItems

  • createGuildSetupItems(__namedParameters): Promise<WebResponse<{
        results: SetupCreateResult[];
    }>>

  • Create missing channels / roles (1-10 per call, 3 calls a minute per server). Only on this click, only with the bot's Manage Channels / Manage Roles; a same-named one that exists is reused (existed: true), so a double click makes nothing twice. Channels are plain text channels; roles have no permissions and are not mentionable. Names are cleaned server side (channels: lowercase-with-dashes). One result per item - one failure never blocks the rest. 429 with Retry-After when over the limit; 503 when the bot cannot reach the server.
