Class APIGuildInGame

Minecraft - game servers connected to a Discord server (Noti-v3 phases/in-game/).

A server running the Noti plugin with no token prints a code (K7P-2QX) to its console. The owner enters it here (createInGameServer), which connects that server to this Discord server and returns its token ONCE; the plugin receives it automatically while it is waiting (delivered: true); otherwise the dashboard shows it once ("paste into plugins/Noti/token.txt").

The plan sets how many servers stay ACTIVE (limits.servers: free 1, Premium 3, Premium Plus 10). A network that shares one token counts once. Over the limit (after a downgrade) the rest are kept but paused: pinned servers first, then the oldest, stay active - active on each server says which. An upgrade brings them back.

Behind the inGame launch flag: every method answers 403 until it is beta/public for the caller.
