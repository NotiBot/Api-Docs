Class APIAdminFeedback

The feedback board - the staff side. Post moderation, tags and bans are staff + developers; boards (and rewriting a post's title / body) are developers only (403 otherwise). None is behind the feedback flag, so boards can be set up before launch. Every change is written to the audit log (getFeedbackAudits).
